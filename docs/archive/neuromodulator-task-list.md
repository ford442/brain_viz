> **Archived.** A completed, one-off implementation checklist for the Phase 21 Custom Neuromodulator UI (now shipped). Kept only for history — see [`docs/ROADMAP.md`](../ROADMAP.md) Phase 21.

1. **Data Model & Profile Definitions:** Create `src/neuromodulators.js`. It will export a `NeuromodulatorProfile` definition and predefined profiles: Dopamine, Serotonin, Acetylcholine, GABA, and a Custom editable one. Verify the file is created with `read_file`.
2. **Compute Shader Integration:** In `src/shaders.js`, update the `TensorParams` struct in `computeShader` (and potentially other shader structs if needed) to replace hardcoded decay and diffusion values in `getRegionPhysics` with uniforms populated from the active profile (e.g. `decayRate`, `diffusionRate`, `retentionBiasX`, `retentionBiasY`, `retentionBiasZ`, `retentionBiasW`). Update `src/brain-renderer.js` to add these properties to `this.params` and write them into the compute uniform buffer (`cBuf`) inside the `render()` loop at exact byte offsets (e.g., offsets 104 and 120, expanding `COMPUTE_UNIFORM_BUFFER_SIZE` from 112 to 144 to fit two new `vec4<f32>` fields, maintaining standard WGSL 16-byte alignment). Verify the changes using `read_file`.
3. **UI Panel Extension:** In `src/ui-panels.js`, create a new exported function `setupNeuromodulatorPanel` and call it from `src/main.js` alongside `setupBciPanel`. Add HTML elements for a profile dropdown, sliders for the profile properties, and a "Save as Custom" button. Wire up event listeners to `window.visualizerAPI` to update the renderer live. Use `localStorage` to load the custom profile during initialization. Verify the changes using `read_file`.
4. **Routine / Marker Event Integration:** Extend the `getAPI` method in `src/routine-player.js` to expose `setNeuromodulator`. Extend `src/routine-handlers.js` with a new `neuromodulator` event handler mapping that calls `player.renderer.setParams` with the specified profile values. Add a demo event to the existing routine 'E' (Visual Cortex Filter) in `src/mini-routines.js` to showcase profile switching. Verify the changes using `read_file`.
5. **Visual Feedback & Legend Update:** Inside `setupNeuromodulatorPanel` (in `src/ui-panels.js`), when a profile changes, update the title text color to match the profile's color. Update the HTML generated in `setupLegendPanel` (in `src/ui-panels.js`) to reflect the new UI and functionality. Verify the changes using `read_file`.
6. **Documentation Update:** Update `README.md`'s descriptions to include the new Neuromodulator UI. Update `agent_plan.md` to check off tasks in Phase 21. Add inline comments explaining the new feature for the autograder. Verify the updates using `read_file`.
7. **Verify Changes:** Run the verification scripts (`python verification/verify_suite.py`) to confirm the code compiles and all existing and new features are working correctly.
8. **Complete pre-commit steps:** Complete pre-commit steps to ensure proper testing, verification, review, and reflection are done.
