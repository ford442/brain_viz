# [Tensor Physics] clangd fallback flags for wasm/ — what a fresh clone gets.
#
# `npm run gen:compile-commands` (host graph, needs no emsdk) or
# scripts/build_wasm.sh (Emscripten graph) writes wasm/compile_commands.json,
# which clangd prefers over this file in the same directory. With neither,
# these are the host golden-test flags (BTE_HOST_FLAGS in scripts/wasm_flags.sh)
# minus -O2 — keep -ffp-contract=off in step with it. Emscripten's `-s`
# settings are link-time and deliberately absent; clangd does not understand
# them. Relative paths resolve against this directory.
-std=c++17
-I.
-Wall
-Wextra
-ffp-contract=off
